# Réparer, libérer, partager — Projet NIRD au cycle 3

Site pédagogique du projet NIRD (numérique inclusif, responsable et durable) pour des classes de CM1-CM2 du Lycée français de Vienne : les élèves apprennent à comprendre, réparer et reconditionner de vieux ordinateurs sous Linux, puis les donnent.

Site en ligne : https://xseorkly.github.io/nird/

## Contenu

- **Le projet** : présentation de la démarche NIRD, des trois piliers et des établissements pilotes.
- **La séquence** : 14 séances en 5 phases. Les 14 séances sont rédigées.
- **Présentation** (`presentation.html`) : le diaporama de présentation du projet aux enseignants, avec les notes de l'orateur (touche N).
- **Espace élève** : fiches à remplir en ligne (enregistrées sur l'appareil de l'élève, rien n'est envoyé), auto-correction, impression.
- **Espace enseignant** : objectifs, matériel, déroulé minuté, corrigés, liens avec les programmes (sciences et technologie 2026, EMC 2024, EDD, CRCN).
- **Les mots** : lexique des mots techniques expliqués pour des élèves de 9-10 ans.

## Fichiers

- `index.html` : toutes les pages du site.
- `assets/style.css` : la mise en forme, y compris pour l'impression.
- `assets/app.js` : navigation, sauvegarde des réponses, auto-correction, lexique.

Les photos sont chargées depuis Wikimedia Commons ; auteurs et licences sont listés dans la page Crédits.

Le site est publié automatiquement sur GitHub Pages à chaque envoi sur la branche `main`.
